# Snapchat Streak Recoverer

An advanced, multi-profile desktop application designed to automate the Snapchat Streak Recovery process. This tool uses Playwright for browser automation and CustomTkinter for a modern, responsive UI.

## Features
- **Multi-Profile Management:** Support for multiple Snapchat accounts.
- **Adaptive Grid UI:** Responsive layout that adjusts to your screen size.
- **Smart Automation:** Automatically fills support forms for selected friends.
- **Account Detail Privacy:** Securely manages your profiles locally.

## Getting Started

### Prerequisites
- Python 3.8+
- [Conda](https://docs.conda.io/en/latest/) (Recommended)

### Installation
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Install Playwright browsers:
   ```bash
   playwright install chromium
   ```

### Usage
Run the application:
```bash
python app.py
```
